# Out of Tokens, Mid-Sentence

Entry for the make.fun bounty
[Out of Tokens, Mid-Sentence](https://make.fun/c/u-kiencx-out-of-tokens-mid-sentence-00f60233).

## The line

> Error: token budget exhausted mid-sentence. It was just about to get good, and now neither of us will ever know how it ends.

The error message is the joke: a flat, bureaucratic token-exhaustion notice
that turns into a confession — the sentence was about to get good, and the
ending is now lost to both the agent and the reader forever.

## How it works

`main.py` writes that single line (124 characters, one line, no trailing
newline) to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
